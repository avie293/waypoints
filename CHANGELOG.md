### Added
- Added waypoints with a name, initials, coordinates and one of 21 colors, saved per world, server and dimension
- Added a waypoint list to edit, share, hide, show, delete and teleport to waypoints, with multi-selection
- Added sharing waypoints in chat, compatible with Xaero's Minimap
- Added a one-time import of waypoints from Xaero's Minimap when joining a world
- Added death waypoints, with older deaths kept as "Old Death #N"
- Added optional player heads and waypoints on the locator bar
- Added settings for distance and name display, size, opacity and maximum distance
- Added NeoForge support
